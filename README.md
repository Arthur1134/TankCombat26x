# Tank Combat 26x

HTML5 tank combat — bounce shots, hold-the-zone missions, solo and local co-op.

## Play

Open `index.html` in a modern browser.

## Version

Current build: see `GAME_VERSION` in `index.html` and `version.json`.

When hosted online, set `UPDATE_CHECK_URL` in `index.html` to your `version.json` URL so the menu can offer updates.
